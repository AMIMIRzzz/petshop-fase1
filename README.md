# Sistema Web - PetShop Amigo Fiel (Fase 1)

Este repositório contém o código-fonte da Fase 1 do projeto da disciplina de Desenvolvimento Web, estruturado exclusivamente com HTML5 semântico (sem CSS, Bootstrap ou JavaScript).

## Funcionalidades da Página Web

1. **Cabeçalho (`<header>`):**
   - Apresenta a identidade visual textual do PetShop Amigo Fiel e um menu de navegação interna com links âncora para facilitar o acesso direto às categorias de produtos, tabela de serviços e informações de contato.

2. **Catálogo de Produtos (`<section id="produtos">`):**
   - Dividido em três categorias principais (**Rações e Alimentação**, **Brinquedos e Acessórios**, e **Higiene e Conforto**).
   - Cada categoria exibe dois produtos distintos contendo imagem ilustrativa (`<img>`), descrição detalhada e valor comercial.

3. **Tabela de Serviços (`<section id="servicos">`):**
   - Apresenta os serviços oferecidos pelo estabelecimento (Banho, Tosa Higiênica, Tosa Completa e Consulta Veterinária), informando a descrição de cada procedimento, o valor cobrado e a disponibilidade do serviço de **tele-busca**.

4. **Rodapé (`<footer>`):**
   - Exibe os dados institucionais, endereço físico, canais de atendimento, horário de funcionamento, links de navegação rápida e direitos autorais.
